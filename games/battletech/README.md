# BATTLETECH — беларускі пераклад

Пераклад гульні **BATTLETECH** (Harebrained Schemes / Paradox, Steam appid 637090).
Агульныя правілы — [AGENTS.md](../../AGENTS.md) і [docs/](../../docs/); стыль —
[STYLE.md](STYLE.md); ацэнка, фарматы і план — [RESEARCH.md](RESEARCH.md); назвы —
[glossary.json](glossary.json).

**Стан на 2026-11-20: падыход да першай хвалі.** Стратэгія крыніцы — C (гібрыд:
англійская дзе знойдзеная, нямецкая дзе не, руская — для спрэчных выпадкаў).
Рухавік `battletech-csv` напісаны (extract/apply), `source/` перачытаны, а
`translation/strings.csv` (21 505 ключоў) сабраны; 16 подпісаў інтэрфейсу ўжо
перакладзеныя. Гласарый запоўнены: G1, G2a, усе 219 планет (G2b) і G2c
(фракцыі і зброя) — 536 запісаў; G3 (персанажы HBS BATTLETECH) дададзены па
вычытцы пробы — усяго 563 запісы, 0 памылак. `batches.json` ёсць,
`ctx:` у працоўных файлах мае `at=/use=/q=/len=`, key-like радкі разбітыя або
пазначаныя `?: re-space`. Спайк у гульні прайшоў: гульня прымае зменены
`strings_ru-RU.csv`, а шрыфты TMP 1.x папраўленыя (усе 9 кірылічных) і
`І і Ў ў` бачныя ў гульні (RESEARCH.md, «Спайк у гульні»). З 2026-11-24 праўка
шрыфтоў і `RussianFontLocTable` — у рухавіку (`belloc patch battletech`).
Рэліза і `CHANGELOG.md` пакуль няма.

**Шрыфты галоўнага меню.** Подпісы `CAMPAIGN`, `CAREER`, `SKIRMISH`, `CREDITS`
у галоўным меню малююцца `UnitedSansReg-Medium` — гэты шрыфт ёсць у штатнай
`RussianFontLocTable` і пераключаецца на Kairos RU. Асобныя экраны (напрыклад,
тытры credits) выкарыстоўваюць `UnitedSansExt-*` без кірыліцы, якіх у штатнай
табліцы няма. Пары «UnitedSansExt-* → Kairos RU» захоўваюцца ў
[`fontmap.json`](fontmap.json); `belloc patch` дапісвае іх у
`RussianFontLocTable` разам са шрыфтамі (`battletech_csv/fonts.py`).

## Як уладкаваны пераклад

- **Адзін файл**: `strings_ru-RU.csv` — плоская табліца `KEY,ru-RU`, 21 507 радкоў
  даных (2 пустыя, 21 505 ключоў). Акрамя яго — 12 субтытраў да відэа
  (`*-Russian.srt`); іх пераклад захоўваецца ў рэпазіторыі асобнай табліцай
  `subtitles.csv` (`file, idx, bel, note`, 228 радкоў), а самі `.srt`
  збіраюцца пры `patch` з таймінгаў гульні. Маніфест, бандлы і код не
  чапаюцца.
- **Ключ — гэта тэкст**: англійскі радок, прыведзены да ніжняга рэгістру, без
  прабелаў, з заменамі (коска → `^`, кропка → `*`, перанос → `newline`); тэгі
  `<…>` прыбіраюцца, а ў спасылках знікае толькі закрыццё `]]` — бачны тэкст і
  `[[…` застаюцца. У рэпазіторыі такі ключ захоўваць нельга — таму ключ у
  `translation/*.csv` — хэш, як у `unity_textasset_csv`.
- **Разметка**: тэгі `<i> <b> <color=…> <size=…>`, аргументы `{…}`, пераносы `\n`,
  спасылкі `[[…]]` — захоўваюцца як у арыгінале; колькасць пераносаў не мяняць.
- **Двукоссі ў тэксце** падвойваюцца пры `patch` (`"` → `""`): `CSVReader` гульні
  лічыць кожнае двукоссе, не абароненае `\`, мяжой ахінальнага поля. Адзіночнае
  двукоссе ў радку злівае з ім усе наступныя радкі ў адзін — і яны не трапляюць
  у слоўнік. Менавіта гэта аднойчы схавала `CAMPAIGN`, `CAREER`, `CREDITS` і
  `MODS`, хоць пераклад у CSV быў.
- **Ключы ўнікальныя** (21 505), але 627 радкоў — паўторы значэнняў (кароткія
  подпісы): эканоміі на гэтым не будзе.

## Назвы

Рашэнні — у [glossary.json](glossary.json), палітыка — у яго `_about`:

- мехі і іншая тэхніка (у тым ліку турэлі) — лацінкай, без перакладу;
- планеты і сістэмы — транслітарацыя ў беларускім пісьме, не пераклад;
- фракцыі — апісальныя назвы перакладаюцца, імёны роду ці кіраўніка
  транслітаруюцца, брэнды застаюцца лацінкай;
- зброя і абсталяванне — коды `LRM`/`SRM`/`AC`/`PPC`/`ER`/`AMS` і пазначэнні
  `+`/`+ +` лацінкай; базавыя назвы (кулямёт, агнямёт, гармата Гауса)
  перакладаюцца, лазеры — «вялікі/сярэдні/малы лазер», `ER` застаецца лацінкай;
- персанажы — транслітарацыя, род — з даных гульні.

Мехі не перакладаюцца не толькі па рашэнні: іх назвы збіраюцца ў гульні з
палёў даных, і ў табліцы для іх амаль няма радкоў — так і ў афіцыйных рускай і
нямецкай лакалізацыях.

## Праца з перакладам

```bash
python -X utf8 -m belloc extract battletech          # ~3–4 хвіліны: табліцы + англійская крыніца
python -X utf8 -m belloc sync battletech             # → translation/strings.csv
python -X utf8 -m belloc glossary battletech         # гласарый → build/glossary.md
python -X utf8 -m belloc batch status battletech     # пачкі (batches.json)
python -X utf8 -m belloc lint battletech
python -X utf8 -m belloc patch battletech --out local/battletech/build/patch
```

`patch` піша `bel` у калонку `ru-RU` і субтытры `<відэа>-Russian.srt` у
`Video/Subtitles/` (для кожнага файла — свой `.orig`/`.bel`); радкі, чый арыгінал
змяніўся пасля перакладу, пакідае як у гульні. Крыніца па радку — `src_lang` у
працоўных файлах пачкі; `src_hash` у рэпазіторыі — ад эфектыўнай крыніцы (EN, DE
або рускай, калі яна пазначаная). Субтытры бяруцца з
`games/battletech/subtitles.csv` (`file, idx, bel, note`); таймінги і нумары —
з рускіх `.srt` гульні. Лакальныя дапаможнікі: `tools/subtitles.py`
`export` (гульня + табліца → `work/subtitles.csv`), `sync` (work → табліца),
`render` (табліца → `build/subtitles/`, прагляд), `check` (зверка з гульнёй).
Пасля праўкі `work/subtitles.csv` — `sync`, потым `render`; `export` — каб
перасабраць work з табліцы пасля абнаўлення гульні. Асяроддзе: Python 3.12 і
`.venv` у корані рэпазіторыя.

`batches.json` ёсць: 94 пачкі ў 8 хвалях (разам з пробай), пакрыццё 100 % (па
адным радку ў пачцы, без прапушчаных). Генератар —
лакальны `local/battletech/tools/make_batches.py`, рукамі файл не правім.
Key-like радкі (2 962) разбітыя на словы або пазначаныя `?: re-space`;
падрабязнасці і парадак каманд — у `local/battletech/tools/README.md`.

Першыя 16 подпісаў інтэрфейсу (галоўнае меню, пауза) ужо перакладзеныя як
праверка ланцуга; `patch --out` сабраў правільны файл, але ў гульні гэтыя радкі
яшчэ не глядзеліся.
