## Як уладкаваны тэкст

Табліцы — па ключы (`common.table_of`):

| табліца | што |
|---|---|
| `vo/nl/<раздзел>` | сюжэтныя рэплікі і думкі Інды па раздзелах (`ch04se01`…), у парадку нумара з ключа |
| `vo/sl/<прамоўца>` | сістэмныя баркі (фашысты, нацысты, рабочыя, Джына, Інды): шмат аднолькавых радкоў у розных галасах |
| `vo/tp/<прамоўца>`, `vo/ef`, `vo/name` | дробнае: размовы ў дарозе, гукі (`\(yawn\)`), імёны |
| `vo/_names` | імёны над субтытрамі: `[name:Fascist]` → ключ «Fascist»; перакладаюцца адзін раз |
| `ui/<група>`, `ui/mission/<месца>` | інтэрфейс, місіі, нататкі, даведнік, дасягненні |

- **Хто кажа** — у `note` працоўных файлаў (`ctx: officerluigi · Fascist`): першае —
  голас з ключа, другое — імя над субтытрам. Род дзеясловаў — па голасе.
- **Пачатак рэплікі** (`[name:…]`, `[p-5]`, `[force]`, `[dist:10]`) у табліцах не
  відаць — рухавік бярэ яго з арыгінала.
- **Захоўваць як ёсць:** `[1.78]` (кавалкі субтытра па часе — колькі ў арыгінале,
  столькі і ў перакладзе), `^I…^I` (курсіў), `^U`, `^S`, `^C"…"`, `<JOY_…>`, `%d`, `%s`,
  `%1$02d`, `\(` `\)`. Бачныя рэмаркі ў дужках (`[grunts]`, `[in Italian]`) — перакладаць.
