# 007 First Light — беларускі пераклад

Пераклад гульні **007 First Light** (IO Interactive; Steam appid 3768760).
Агульныя правілы — [AGENTS.md](../../AGENTS.md) і [docs/](../../docs/); стыль —
[STYLE.md](STYLE.md); план і рашэнні карыстальніка — [PLAN.md](PLAN.md); ацэнка і
фарматы — [RESEARCH.md](RESEARCH.md) (`research/` — аднаразовыя скрыпты, не
падтрымліваюцца); вычытка — [REVIEW.md](REVIEW.md).

> Нейрапераклад: тэкст перакладзены моўнай мадэллю, чалавекам цалкам не вычытаны.
> Нейрапераклад: мадэль Claude (Anthropic). Кіраўнік праекта: Віталь Аляхновіч.

```bash
python -X utf8 -m belloc extract 007-first-light   # rpkg → local/007-first-light/source/{en,ru,uk}.json + context.json (~2 хв)
python -X utf8 -m belloc sync 007-first-light      # → translation/ui/*.csv, translation/dlg/<місія>/<сцэна>.csv
python -X utf8 -m belloc lint 007-first-light
```

## Як уладкаваны тэкст

| табліца | што | ключ |
|---|---|---|
| `ui/<рэсурс>` | LOCR: меню, гаджэты, задачы, дасье, лісты, падказкі | хэш радка (8 hex) |
| `dlg/<місія>/<сцэна>` | DLGE: субтытры сцэны ў парадку гульні | `<рэсурс>:<нумар WavFile>` |
| `dlg/<місія>/_shared` | субтытры некалькіх сцэн місіі | |
| `dlg/_common/<катэгорыя>/<голас>` | агульныя рэплікі з розных місій (баркі) | |
| `dlg/_speakers` | імёны прамоўцаў над субтытрам | `імя` або `імя\|пол` (`Civilian\|ж`) |

Ключы — хэшы з файлаў гульні, тэксту ў іх няма.

- **Сцэны** (`scenes.py`): хэш шляху — MD5, як у Hitman, але суфікс без «pc_»
  (`[assembly:/…/x.brick].entitytype`). Ад сцэн з packagedefinition.txt — пошук па
  спасылках; рэпліка — да бліжэйшай сцэны; парадак у сцэне — абыход спасылак (у
  размовах — парадак гульні, зрэдку пераблытаны). Сюжэт (кат-сцэны, Бонд, сувязь)
  прывязваецца да сцэны ў 97–99 %, NPC — ~40 %. Місіі і іх храналогія —
  `glacier.missions` у game.json (з JSON гульні KNT_Missions).
- `ui/` — па хэшы рэсурсу LOCR (імёны LOCR не шукаліся).
- **Кантэкст субтытра** — лакальна ў `note` працоўных файлаў: `ctx: CIVUKF01 ж ·
  Civilian · NPC_Story` — код голасу, **пол (род дзеясловаў)**, імя на экране,
  катэгорыя (`Cinematic_*`, `Bond`, `Buddy`, `Comms_*`, `NPC_*`, `AI_*`, `Special_*`).
  Пол — з канца кода (`…F01` / `…M03`); у названых герояў (BOND, Q, M, GREENWAY…) кода
  полу няма — гл. гласарый.
- **Імёны прамоўцаў** перакладаюцца ў `dlg/_speakers` адзін раз; зборка ставіць іх ва
  ўсе субтытры. Пол — частка ключа (у рускім слоце асобна мужчынскі і жаночы
  варыянт). `{0}` у імені (`Guest{0}`) — нумар, захоўваць.
- **Юрыдычныя тэксты** (`ui/01179467BC0E9F2F`: EULA, privacy — 6 радкоў) застаюцца
  **англійскімі** (рашэнне карыстальніка 2026-10-27). У рэпазіторыі іх `bel` — заглушка
  `[]` (`from_original` у game.json): рухавік бярэ англійскі радок з гульні. Пачкі іх
  абмінаюць (лакальна ў `note` — `ctx: legal`).
- Субтытр у гульні = загаловак (`//[код]\\//{імя}\\//##колер#\\…\\`) + кавалкі з
  таймінгамі `//(0,2.3)\\тэкст//(2.3,4.5)\\тэкст…` (11 % рэплік — 2–17 кавалкаў; у
  кожнай мове свая разбіўка). У CSV — толькі тэкст, кавалкі праз `\n`. Пры зборцы
  загаловак — са слота `ru`, таймінгі — **англійскія** (агучка англійская): радок `bel`
  на кавалак; іншая колькасць радкоў — таймінгі прапарцыйна (`dlge.join`).

### Разметка

| што | як |
|---|---|
| `<br>`, `<br/>`, `<b>…</b>`, `<u>…</u>`, `<li>` | тэгі LOCR — захоўваць |
| `{0}`, `{1}` | плэйсхолдары — захоўваць |
| `{ES_GadgetView}`, `{ES_Grab/NoGesture}`, `{Accept}`… | значкі кнопак кіравання — захоўваць як ёсць |
| `{Hold}`, `{Press}` | бачныя подпісы ў дужках (рускі слот іх перакладае) — `{Утрымліваць}`, `{Націснуць}`; лінтэр `placeholders` на іх — чаканы |
| `&quot;` | HTML-сутнасць у LOCR — пакідаць |
| `[Laughs]`, `[In Serbian]` | рэмаркі ў субтытрах — бачныя, перакладаць (у дужках) |
| `\r\n` у тэксце | сапраўдныя пераносы (лісты, дасье) — захоўваць |

## Пачкі і агенты

`batches.json` — 61 пачка ў 3 хвалі: u — імёны прамоўцаў і інтэрфейс, m — місіі па
храналогіі, сцэна за сцэнай, c — агульныя рэплікі. Паўторы (`_repeats`: той жа EN і
прамоўца/пол; у інтэрфейсе — EN+RU) у пачкі не трапляюць — `batch apply` дае ім
пераклад першага выпадку, таму пераклад рэплікі мусіць падыходзіць да любога месца,
дзе яна гучыць. Даведнік рашэнняў хвалі 1 (~960 тэрмінаў) і нататкі пачак —
лакальна: `local/007-first-light/TERMS.md`, `work/*.terms.md` (у іх англійскія назвы
інтэрфейсу — у рэпазіторый не кладуцца). Пары EN → bel па ключы аднаўляюцца са
сваёй копіі гульні.

Да шаблона [docs/agent-brief.md](../../docs/agent-brief.md) — асаблівасці гульні:

- Слупкі працоўнага файла: `table, key, en, ru, uk, bel, note`. Перакладаем з `en`;
  `ru` і `uk` — падказкі сэнсу, роду, ты/вы, не ўзор.
- `dlg/<місія>/<сцэна>` — рэплікі адной сцэны ў парадку гульні: чытаць як размову (хто
  каму адказвае, хто з кім на «ты»). Місіі: M01 Ісландыя, M02 MI6/Мальта (трэніроўкі),
  M03 Славакія, M04 Маўрытанія, M05 Кенсінгтан, M06 Англія, M07 В'етнам, M08 MI6, M09
  Антарктыда, M10 MI6. **Фонавыя гутаркі NPC часта стаяць у адваротным парадку**
  (адказ раней за пытанне) — тады чытаць знізу ўверх.
- **Кавалкі субтытра**: у `bel` — столькі ж радкоў, колькі ў `en`, кожны — пераклад свайго
  кавалка (тады тэкст ідзе сінхронна з голасам); рускі разбіты па-свойму — на яго
  колькасць радкоў не глядзець.
- Імёны прамоўцаў (`dlg/_speakers`) — толькі ў пачцы u00, па полу ў ключы.

## Дастаўка — патч-архіў (праверана ў гульні 2026-10-26)

Беларуская — **на месцы рускай** (слот `ru`): англійскі шрыфт кірыліцы не мае,
рускі мае `І і Ў ў`. Гулец выбірае рускую мову — у наладах яна называецца
«Беларуская» (`<locale ru>…</locale>` у `ui/01B4B8D71B46C3B8`, рашэнне карыстальніка
2026-10-27). Агучка застаецца англійскай (рускай агучкі ў гульні няма).

```bash
python -X utf8 -m belloc patch 007-first-light --out local/007-first-light/build/check   # праверка: файлы ў папку
python -X utf8 -m belloc patch 007-first-light                                           # у гульню
python -X utf8 -m belloc patch 007-first-light --restore                                 # выдаліць
```

`patch` піша `chunk0patchN.rpkg` / `chunk1patchN.rpkg` (N — афіцыйны `patchlevel` + 1)
з перабудаванымі LOCR/DLGE і падымае `patchlevel` партыцый у `packagedefinition.txt`
(арыгінал — `.orig`). Нашы файлы пазначаныя `<файл>.bel` (SHA-256): `extract` іх не
чытае, `--restore` выдаляе толькі іх. Калі Steam абнавіў гульню — за аснову бярэцца
новы `packagedefinition.txt`. Файлы гульні не перазапісваюцца.

**Для гульцоў** — `belloc package 007-first-light` (exe ~21 МБ + кароткі ЧЫТАЙ.txt з
`release/readme.txt`) і `belloc catalog 007-first-light` (пакет для лаўнчара). У
payload — ключы-хэшы і ключы XTEA, англійскага тэксту няма.
