# Новая гульня: шлях лакалізацыі па кроках

Каманды — з кораня рэпазіторыя: `python -X utf8 -m belloc <каманда> <гульня>`
(на Windows `-X utf8` абавязковы). `<гульня>` — імя папкі ў `games/`.

Перад пачаткам — [AGENTS.md](../AGENTS.md): **арыгінальны тэкст гульні і чужыя
пераклады ў рэпазіторый не трапляюць ніколі**. Усё, дзе ёсць тэкст гульні
(`source/`, `work/`, `build/`), ляжыць у `local/<гульня>/`.

```
games/<гульня>/                     у рэпазіторыі — толькі наша
  game.json                         канфіг: рухавік, мовы, release, credits
  README.md                         стан, асаблівасці, што праверана ў гульні
  STYLE.md                          тон, ты/вы, род, лаянка, разметка, рашэнні
  glossary.json                     назвы: імёны, месцы, рэчы, тэрміны
  batches.json                      пачкі для паралельнай працы агентаў
  translation/**/*.csv              key, src_hash, bel, note
  lint_allow.txt, textures.json, release/, RESEARCH.md, PLAN.md, research/, CHANGELOG.md
local/<гульня>/                     толькі ў вас
  local.json                        {"game_dir": "…"} і перавызначэнні game.json
  source/                           тэкст гульні: <мова>.json, context.json, meta.json
  glossary.local.json               лакальны слой гласарыя: запісы з цытатамі тэксту гульні
  work/, build/                     працоўныя файлы пачак, даклады, зборкі
```

## 0. Ацэнка — `RESEARCH.md`

Да перакладу адказаць, ці варта браць гульню і колькі гэта каштуе:

- **рухавік і фармат тэксту** — ці ёсць ужо рухавік у `core/belloc/engines/`
  ([engines.md](engines.md)); калі не — колькі працы на экстрактар і зборку;
- **аб'ём** — радкі і словы арыгінала; парадак кошту — па словах;
- **ці ёсць афіцыйная руская** — падказка для кантэксту і месца, якое займе беларуская;
- **шрыфты** — ці ёсць кірыліца і `І і Ў ў`, «», ’;
- **як даставіць гульцу** — патч файлаў, мод, слот мовы; ці правяраюць файлы (CRC, подпісы).

Пробныя скрыпты — у `research/` гульні (у README: «аднаразовыя, не падтрымліваюцца»).
Тэкст гульні ў RESEARCH.md не цытаваць — толькі лічбы, назвы файлаў, структура.

## 1. Канфіг

`games/<гульня>/game.json`:

```json
{"name": "Silver Pines", "engine": "unity-localization", "steam_appid": 0,
 "source_lang": "en", "hint_lang": "ru",
 "credits": "Нейрапераклад: мадэль Claude (Anthropic). Кіраўнік праекта: …",
 "unity": {"…": "палі рухавіка — docstring engines/<рухавік>/__init__.py"}}
```

- `hint_lang` — мова-падказка (звычайна афіцыйная руская), можа быць `null`;
  `extra_hints` — дадатковыя (`["uk"]`);
- `lint_args` — дадатковыя аргументы лінтэра (напр. `["--tag-re", "<[^<>]+>"]`);
- `from_original` — рэгулярка нябачных кавалкаў, якія пераклад пакідае як у арыгінале
  (рэмаркі акцёрам): у рэпазіторыі яны — заглушка `[]` (гл. `core/belloc/tables.py`);
- лакальнае (шлях да гульні, калі Steam яе не знаходзіць; свае шрыфты) —
  `local/<гульня>/local.json`, не ў game.json.

## 2. Тэкст гульні і табліцы

```bash
python -X utf8 -m belloc extract <гульня>     # файлы гульні → local/<гульня>/source/
python -X utf8 -m belloc sync <гульня>        # source/ → translation/*.csv + прагрэс
python -X utf8 -m belloc stats <гульня>       # толькі прагрэс
python -X utf8 -m belloc dicts                # слоўнікі лінтэра (раз на машыну)
```

Пераклад пішацца ў слупок `bel`. Калі арыгінал у гульні змяніўся, `sync` пераносіць
стары `bel` у `note` як `stale: …` і ачышчае `bel` — такія радкі трэба пераглядзець.
Працаваць з CSV — праз `tables.load_all` / `tables.save` (там тэкст гульні далучаецца
ў памяці і выразаецца пры запісе) або праз пачкі (крок 4).

## 3. Стыль і гласарый

- **`README.md` гульні** — рухавік, як уладкаваная лакалізацыя, ключы, род гульца,
  стан. Сюды — тое, што трэба ведаць кожнаму, хто адкрые гульню ўпершыню.
- **`STYLE.md`** — тон, ты/вы, род гульца і персанажаў, як перадаваць лаянку,
  разметку і тэгі, устойлівыя рашэнні. Кароткія цытаты-прыклады — можна (радок, каб
  паказаць правіла).
- **`glossary.json`** — адзіная крыніца праўды па назвах: секцыі (`characters`,
  `places`, `items`, `terms`…) → `{арыгінал: {bel, gender?, note?, alt?, ru?}}`;
  секцыі на `_` — каментары; `bel: "гл. <ключ>"` — спасылка. Толькі назвы, па
  некалькі слоў, **без апісанняў і цытат**. Праверка: `belloc glossary <гульня>`.
- **`local/<гульня>/glossary.local.json`** — лакальны слой у тым жа фармаце (неабавязковы):
  рашэнні, дзе ключ або заўвага — цытата тэксту гульні (дэвізы, рэплікі, фразы). Лінтэр,
  `glossary` і даведнікі чытаюць абодва слаі; аднолькавы ключ — бярэцца лакальны.

Новую назву спачатку ўпісаць у гласарый, потым ужываць. Брэнды і вымышленыя абрэвіятуры
звычайна застаюцца лацінкай — рашэнне ў `note`. Ігравыя тэрміны — без калек з рускай
(AP → АД, не ОД; target → цэль).

## 4. Пачкі і хвалі — `batches.json`

Каб некалькі агентаў перакладалі адначасова і не сутыкаліся, радкі дзеляцца на пачкі
(фармат — docstring `core/belloc/batch.py`). Кожны радок — роўна ў адной пачцы
(`batch status` паказвае пакрыццё). Пачкі групуюцца ў **хвалі**: першай — тэрміны,
інтэрфейс і назвы; апісанні, лор і дыялогі, што на іх спасылаюцца, — пасля.

```bash
python -X utf8 -m belloc batch status <гульня>
python -X utf8 -m belloc batch export <гульня> --wave 1      # → local/<гульня>/work/<пачка>.csv
#   … агенты перакладаюць (docs/agent-brief.md) …
python -X utf8 -m belloc batch apply <гульня> --wave 1       # bel/note → translation/*.csv
```

Каардынатар (асноўная сесія): `export` перад хваляй, задання агентам па
[agent-brief.md](agent-brief.md), `apply` пасля, затым лінтэр, праўкі гласарыя і
STYLE.md з `work/*.terms.md`, каміт. `apply` пераносіць толькі непустыя `bel` і
адкідае радкі, чый арыгінал змяніўся.

**Мадэль для перакладу — толькі топавая** (зараз — Claude Opus 5.5).

## 5. Праверкі

```bash
python -X utf8 -m belloc lint <гульня>              # → local/<гульня>/build/lint_report.md
python -X utf8 -m belloc glossary <гульня>          # → build/glossary.md
python -X utf8 -m belloc idioms <гульня>            # выразы «Антыкалькі» ў рускім слупку → build/idioms.md
python -X utf8 -m belloc fantasy-report <гульня>    # тэрміны фэнтэзі → build/fantasy.md
python -X utf8 -m belloc antykalka выглядеть --exact
```

- **Лінтэр.** Моўныя праверкі: `spell`, `names`, `ruwords` (галоўны дэтэктар
  русізмаў), `ruletters`, `rusuffix`, `ushort` (у/ў), `latin`. Білінгвальныя: `tags`,
  `placeholders`, `ws`, `endpunct`, `lenratio`, `dupes`, `untranslated`, `glossary`.
  Лішнія опцыі: `--checks tags,placeholders`, `--skip names`, `--tag-re REGEX`.
  Белы спіс — `core/belloc/lint/allow_common.txt` (агульнае) і `lint_allow.txt` гульні.
- **«Антыкалька»** — даведнік, не аўтаправерка: глядзець на словы, падобныя на рускія,
  і на ўстойлівыя выразы ў дыялогах. Правапіс слоўніка — тарашкевіца; пурызмы не браць
  аўтаматычна. `idioms` — спіс для вычыткі, не вердыкт.
- **Вычытка** — асобны праход па гатовых табліцах: род, ты/вы, паўторы, галасы.

## 6. У гульню

```bash
python -X utf8 -m belloc fonts <гульня> --text      # якія літары перакладу шрыфты не пакрываюць
python -X utf8 -m belloc patch <гульня> --out local/<гульня>/build/patch   # вынік у папку, гульня не чапаецца
python -X utf8 -m belloc patch <гульня>             # у гульню (арыгіналы — .orig побач)
python -X utf8 -m belloc patch <гульня> --restore   # вярнуць арыгіналы
python -X utf8 -m belloc textures <гульня>          # прэв'ю надпісаў на тэкстурах (калі ёсць)
```

- `patch` мяняе файлы гульні — для праверак спачатку `--out`.
- Шрыфты амаль заўсёды рускія: няма `І і Ў ў` — прыёмы ў [engines.md](engines.md).
- Праверка ў гульні: меню, кароткія подпісы (беларускія словы даўжэйшыя), выбары,
  субтытры, шрыфты, надпісы. Вынік — тэкстам у README гульні; **здымкі экрана ў
  рэпазіторый не кладуцца**.
- Пасля абнаўлення гульні ў Steam: `extract` → `sync` → перагледзець `stale` → `patch`.

## 7. Рэліз

```bash
python -X utf8 -m belloc package <гульня>    # → local/<гульня>/build/release/<file>_<version>.zip
```

Секцыя `release` у game.json (палі — docstring `core/belloc/release.py`): назва,
версія, exe гульні, як завецца мова ў меню і якую замяняе, тэксты ЧЫТАЙ.txt.
У exe — толькі наш тэкст па ключах і нашы файлы (вольныя шрыфты); усталёўшчык патчыць
гульню на камп'ютары гульца. Архіў гатовых файлаў — толькі для рухавікоў, дзе вынік
цалкам наш (Paradox).

Праверка перад выкладкай — exe на **копіі** гульні (`--game <копія>`): усталёўка,
паўтор, «праверка цэласнасці» (Steam вярнуў арыгінал), выдаленне; вынік параўнаць з
`patch --out`.

- **Подпіс** — `credits` з game.json ва ўсім публічным (README, рэліз, ЧЫТАЙ.txt,
  усталёўшчык) і яўная заўвага, што тэкст — нейрапераклад, чалавекам цалкам не
  вычытаны. Слова — «абдрукоўка», не «апячатка».
- `CHANGELOG.md` гульні — што змянілася ў версіі.
- Для лаўнчара і напамінаў у exe — `belloc catalog <гульня>`: пакет перакладу і
  запіс у каталог ([launcher.md](launcher.md)).
